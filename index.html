NEWSCOPE PROJECT

NewsScope

A lightweight web application that automatically gathers news from configurable online sources and filters articles by specific topics.

View Source Code GitHub Repository

🔎 News Search

Search and filter collected news articles by configurable topics and keywords.

⚡ Automatic Scraping

Automatically collects news from configured RSS, Atom and web sources.

📰 Multiple Sources

Add and manage different news sources through the application configuration.

💾 SQLite Database

Stores collected articles while preventing duplicate URLs.

Built with Python · Flask · BeautifulSoup · Feedparser · SQLite
